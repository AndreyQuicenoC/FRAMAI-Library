# Contributing to VEXARQ

Thank you for your interest in contributing.

## How to contribute

1. Fork the repository and create a branch from `main`.
2. Keep changes focused and aligned with the adaptive multi-agent design.
3. Update `CHANGELOG.md` under `[Unreleased]` or the next version section.
4. Do not add emojis to README, prompts, or generated UI guidance; use icons where visual cues are needed.
5. Open a pull request with a clear description and test plan.

## Scope guidelines

- **In scope:** Prompt improvements, XML structure fixes, templates, documentation, standards.
- **Out of scope:** Unrelated refactors, new workflows without discussion, breaking changes without a major version bump.

## Commit messages

Use [Conventional Commits](https://www.conventionalcommits.org/):

- `feat:` new capability
- `fix:` bug fix
- `docs:` documentation only
- `refactor:` internal restructuring without behavior change
